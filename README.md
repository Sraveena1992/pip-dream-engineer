## 📖 About Pip (Character Profile)

* **Name:** Pip
* **Role:** Junior Dream Engineer `@` The Midnight Nursery
* **Who They Are:** A starry-eared, cute baby character with smooth skull contours, cozy glowing pinpricks of light in their eyes, and a bedtime nightcap with stars and a pink bow.
* **Personality:** Curious, sleepy, a little clumsy, easily delighted. Giggles at everything and hates silence.
* **Tagline:** *“I build the dreams you fall asleep inside.”*

## ✨ Features & Interactive Modules

### 1. 🎵 The Lullaby Lab
* **Web Audio API Chime Synthesizer:** Real-time browser audio generation for sleep frequencies (`C4`, `E4`, `G4`, `C5`).
* **Auto-Play Melody:** Interactive sequence button that plays a soothing bedtime lullaby.

## 🛠️ Tech Stack

* **Frontend:** Vanilla HTML5, CSS3 (CSS Custom Properties & Glassmorphic UI)
* **Scripting:** Modern ES6+ JavaScript
* **Audio Engine:** Web Audio API (`OscillatorNode`, `GainNode`)
* **Graphics & FX:** HTML5 Canvas (Starfield & Interactive Sparkle Particles), SVG Pathing
